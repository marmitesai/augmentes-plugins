# kit-plaud

Vos réunions enregistrées au Plaud deviennent : une note propre dans votre
coffre, un compte-rendu prêt à partir, et les brouillons de mails qui en
découlent. Rien ne part jamais tout seul : vous relisez, vous corrigez, vous
envoyez.

Le cœur de la recette est la **page de correction** : la transcription
automatique se trompe (locuteurs inventés, noms déformés, chiffres approximatifs),
c'est vous qui validez, pas l'IA.

## Installation

1. Décompressez l'archive dans `~/.claude/skills/`
2. Copiez `config.example.json` en `config.json` et remplissez-le
3. Suivez `setup/SETUP.md` (ou dites « installe le kit plaud » à votre assistant)

## Ce qui reste chez vous

Votre compte Plaud, vos transcriptions, votre config : tout vit sur votre
machine. Les brouillons se créent dans votre messagerie, jamais envoyés.
